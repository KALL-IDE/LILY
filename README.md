# LILY - Pink Cat Puzzle

This repository contains the LILY Unity project: a 2D pink-themed puzzle where you control a cat that pushes crates to reach salmon targets. The project includes scripts, prefabs, scenes, and basic placeholder art so you can open and build it in Unity.

Unity version: 2022.3 LTS (recommended)
Renderer: Built-in (default)
Target: Android (default)

Quick start
1. Clone the repo:
   git clone https://github.com/KALL-IDE/LILY.git
2. Open Unity Hub and choose 'Open' and point to the cloned folder.
3. Open the scene `Assets/Scenes/Level1.unity` (or MainMenu scene) and press Play.

If you need a ready-to-install APK, let me know and I will prepare the build and instructions.
