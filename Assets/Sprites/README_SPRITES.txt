Sprites placeholder instructions

Because binary sprite files are large and Unity-specific, I added instructions
and placeholders rather than committing raw PNGs. To create simple placeholder
sprites in the Editor:
1. GameObject -> 2D Object -> Sprite -> Square.
2. Use the SpriteRenderer color property to tint the square (pink for Cat, darker pink for Crate, salmon for Goal).
3. Save as prefabs by dragging them into Assets/Prefabs/.

If you prefer, provide PNG files and I will add them to Assets/Sprites/ and wire them into the prefabs.
