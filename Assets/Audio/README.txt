This folder contains the background music placeholder used in the project.

I couldn't attach the exact track you requested (copyright restrictions + you didn't upload the file). When you have the audio file you can replace this placeholder.

Suggested royalty-free loop (you can download and add to Assets/Audio):
- https://freesound.org/people/InspectorJ/sounds/352520/  (example ambient loop)

To replace the music in Unity:
1. Import your audio file into Assets/Audio.
2. Select the GameManager GameObject in the scene and add/assign the AudioSource clip to your file. Ensure Loop is checked.
3. Save and build.
